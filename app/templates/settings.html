{{ icon('download', 'left') }}Export ZIP

Import from a previously exported ZIP (older exports too), or from one CSV file of an export under its export name (such as warframe.csv): only that file's data changes. Rows in the file overwrite yours for the same item, new items are added, and anything the file does not name is kept. The file is checked first: one invalid cell refuses the whole import and nothing is written.
