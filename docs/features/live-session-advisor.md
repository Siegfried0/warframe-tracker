# Live Session Advisor

The Live Session Advisor, in the [Farming Planner](farming-planner.md), helps you make the most
of the mission you are running right now.

Set the mission node you are farming now (search it by name) to surface the drop
opportunities at that node across all your active goals; **Clear Node** removes it. The nodes offered are the mission locations the drop data of the
last [wiki sync](wiki-sync.md) knows (relics themselves are not offered).

- Each opportunity shows the drop chance at the current node, the optimal farming node's drop
  chance, and an efficiency rating (Optimal / Acceptable / Poor).
- A guaranteed-drop flag highlights when the node's primary drop is near-certain, making even
  low-probability side drops essentially free.
- A collapsible harvest summary lists every drop at the node with its drop chance and the
  number of it expected in 10 runs.

The node you set is kept in your browser session only: it is not saved with your data (nor
exported), and clearing it ends the session advice.
